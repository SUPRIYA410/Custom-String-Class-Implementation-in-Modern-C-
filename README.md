# Custom-String-Class-Implementation-in-Modern-C-
Implemented a Custom String Class in Modern C++ to understand dynamic memory allocation, deep copying, constructors, destructors, and operator overloading. Implemented string operations such as concatenation, comparison, assignment, and length calculation, strengthening my understanding of OOP and memory management in C++.

📌 Project Overview
This project implements a Custom String Class in C++ without relying on the predefined std::string class. It demonstrates how string operations can be implemented using dynamic memory allocation, constructors, destructors, and operator overloading.

🎯 Objectives
- Understand dynamic memory allocation using new and delete[].
- Implement deep copy using a copy constructor.
- Understand operator overloading.
- Manage memory efficiently.

-->Explore Object-Oriented Programming concepts in C++.
